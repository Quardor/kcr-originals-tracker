# kcr-frontend

SPA фронтенд системы учёта оригиналов документов (KCR Originals Tracker). Работает поверх
REST API бэкенда `server/kcr-backend` (префикс `/api/v1`).

## Стек

- React 18 (JavaScript) + Vite
- react-router-dom — маршрутизация
- без UI-библиотек и CSS-фреймворков — единый `src/styles.css`
- без axios — fetch-обёртка с автопродлением JWT (`src/api/client.js`)

## Возможности

- вход и регистрация (регистрация создаёт оператора);
- справочник клиентов: поиск по коду KCR/ИНН, фильтры (тип, KCR действует/заблокирован,
  признак, этап работы, ответственный — любой/только мои/свободные), сортировка, пагинация;
- карточка клиента: все поля, блок работы (этап, ответственный, следующий контакт),
  единая история с датой, временем и автором (звонки с результатом/договорённостью/сроками
  и ссылкой на запись, письма, комментарии, системные события), претензии с санкциями;
- операторский цикл: «Взять в работу» (атомарно, одному клиенту — один ответственный),
  смена этапа (оператор — рабочие этапы своих клиентов, админ — любые), переназначение
  и освобождение ответственного (админ), события звонка/письма/комментария;
- «Сегодня нужно» (`/today`): клиенты с наступившим сроком следующего контакта —
  оператор видит своих, администратор всех;
- создание и изменение клиента (только администратор; PATCH — только заполненные поля);
- импорт из Excel: предпросмотр без записи и применение, отдельные выгрузки клиентов
  и срезов (только администратор; у срезов — выбор отчётного периода).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # локальный просмотр собранного dist/
```

Бэкенд должен быть доступен по адресу из `VITE_API_BASE_URL` (по умолчанию
`http://localhost:8080/api/v1`; CORS бэкенда в dev разрешает origin `http://localhost:5173`).
Значение переопределяется через `.env` (см. `.env.example`).

## Структура

```
src/
├── api/          — доступ к REST API: client.js (fetch-обёртка, refresh-ротация
│                   single-flight — параллельный refresh отзывает семейство токенов),
│                   auth.js, clients.js, events.js, claims.js, worklist.js, imports.js,
│                   errors.js (коды → русский текст)
├── auth/         — сессия: jwt.js (декод claims: id, имя, роль), AuthContext.jsx
├── components/   — Layout, Protected, Pagination, ui.jsx, EventForm, HistoryFeed,
│                   ClaimsSection
├── labels.js     — русские подписи справочников (этапы, типы событий, статусы)
└── pages/        — Login, Clients, ClientCard, ClientForm, Import, Today, NotFound
```

Роли берутся из claims access-токена (`sub`, `preferred_username`, `roles`); проверка прав на
бэкенде — UI-ограничение по роли только скрывает недоступное.
